# Тестовое задание BI: ClickHouse + FastAPI

## База данных

ClickHouse в Docker. Параметры подключения и обработки лежат в `.env`.

```bash
docker compose up -d
```

## Структура данных и заполнение таблиц

При старте контейнер `app` создаёт 5 таблиц и заполняет их тестовыми данными (1000 записей), связанными по ключам.

```bash
docker compose up --build
```
